# 实时标签组隐私说明

更新日期：2026-11-11

实时标签组用于整理 Chrome 原生标签组。GitHub Releases 用户安装包不要求注册账号，也不调用云端 AI 服务。

## 处理的数据

扩展读取已打开标签页的网址、标题、窗口和标签组信息，用于判断哪些网页应成组以及生成组名。它在 Chrome 本机保存分类规则、自动分组决策和操作记录；记录可能包含网页标题、网站域名、去除查询参数与片段后的网页路径，以及标签组名称。网页路径仍可能包含个人信息。

## 数据去向

GitHub Releases 用户安装包不向开发者服务器上传这些数据，不向第三方出售或共享。数据保存在用户自己的 Chrome 扩展存储和 IndexedDB 中。开发者使用的本机工作台与 Native Messaging 备份程序不包含在用户安装包内，也不会因安装该版本而运行。

## 用户控制

用户可以在 Chrome 标签栏修改组名或移动网页；扩展会尽量保护手动修改的组。扩展卸载或清除其本机存储会影响已保存的规则和记录。请在操作前自行保留需要的数据。

## 联系方式

产品 GitHub 仓库建立后，可通过仓库的问题反馈入口联系维护者。此说明随公开源码一同提供。
