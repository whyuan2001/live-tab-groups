# Microsoft Edge 加载项商店资料：实时标签组 1.0.0

- 名称：实时标签组
- 类别：效率工具
- 简短说明：自动整理同网站的 Edge 标签页；多选网页也能手动成组并自动命名。
- 隐私政策公开地址：`https://github.com/whyuan2001/live-tab-groups/blob/main/EDGE_PRIVACY.md`（文件进入 main 后再填写）

## 详细说明

实时标签组帮助整理长期打开的网页。同一窗口里有两个以上来自同一网站的网页时，扩展会建立并命名 Edge 原生标签组。将网页从另一个窗口拖入后，也会重新判断。

要把不同网站的网页放在一起，可在标签栏按住 Ctrl 选中至少两个未固定、未分组的标签页，稍等片刻即可得到一个自动命名的标签组。仍可用 Edge 原生操作修改名称或移动网页。

点击扩展图标中的“立即更新分组”可以重新整理当前窗口。安装新版扩展后，点击提示中的“更新”可将新规则应用到已经打开的窗口，并尽量保护手动创建或修改的组。

数据保存在用户本机，不需要账号，不调用云端 AI，也不向开发者服务器上传网页标题或网址。

## 权限用途

- `tabs`：读取标签页标题、网址和窗口位置，用于分类及命名。
- `tabGroups`：创建、命名和调整 Edge 原生标签组。
- `storage`：在浏览器本机保存规则、版本应用状态与分组归属。
