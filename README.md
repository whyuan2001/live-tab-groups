# 实时标签组 · Live Tab Groups

让一直打开的网页保持有序：自动把同网站网页整理成 Chrome 原生标签组；按住 ⌘（Mac）或 Ctrl（Windows/Linux）多选未分组网页时，也能手动成组并自动命名。

## 安装

1. [直接下载 `live-tab-groups-v1.0.0-install.zip`](https://github.com/whyuan2001/live-tab-groups/raw/refs/heads/main/downloads/live-tab-groups-v1.0.0-install.zip)，解压到一个准备长期保留的文件夹。确认打开该文件夹时能直接看到 `manifest.json`。
2. 在 Chrome 打开 `chrome://extensions`，开启右上角**开发者模式**，点击**加载已解压的扩展程序**，选择上述文件夹。
3. 将“实时标签组”固定在工具栏。打开两个同网站网页，确认顶部出现标签组。

安装 ZIP 是用户运行包；仓库的 **Code → Download ZIP** 是源码包，不能直接作为上述安装文件夹。此方式属于开发者模式加载，不提供商店的一键安装与自动更新。

## 更新

下载新版本的安装 ZIP，解压并**覆盖原安装文件夹中的文件**，保持原文件夹位置不变；然后在 `chrome://extensions` 找到“实时标签组”并点击**重新加载**。换一个文件夹重新安装可能产生新的扩展 ID，使原有扩展数据无法自动沿用。扩展加载新代码后，若弹窗提示“检测到新版本，请更新”，点击**更新**，才会按新策略整理已打开的标签组。请区分“重新加载新代码”和“应用新分组策略”两个步骤。

## 功能

- 同一窗口中，至少两个同网站网页自动成组和命名。
- 跨窗口拖入网页后重新判断。
- ⌘ / Ctrl 多选未固定、未分组的网页，自动建立带建议名称的手动组。
- 用户直接在 Chrome 标签栏改名、移动网页；更新策略时保护手动修改。
- 扩展代码更新后，由用户点击“更新”才整理现有标签组。

## 源码与维护

需要支持 Manifest V3 的 Chrome 与 Node.js。运行 `npm test`、`npm run evaluate`、`npm run check` 验证核心逻辑；`npm run build:github` 生成用户安装 ZIP。公开安装包只包含用户侧分组功能；本机工作台与 Native Messaging 同步属于开发者维护工具，不是用户安装步骤。

## 隐私

用户安装包不调用云端 AI，也不上传网页标题或网址到开发者服务器。具体数据处理见 [隐私说明](PRIVACY.md)。
